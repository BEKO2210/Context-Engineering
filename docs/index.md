# Context Engineering — Documentation Index

## Overview

This repository is a template for **context-engineered AI-assisted development**.
It combines structured context files (AGENTS.md, prompts, patterns) with a
closed-loop benchmark system that scores repository health on every change.

Created by **Belkis Aslani**.
